# Development and source

The [source repository](https://github.com/viell-dev/slop-effect-schema-http) contains the
implementation, tests and documentation. Agents maintain the project; its code is not
human-reviewed. It is available under the [MIT
license](https://github.com/viell-dev/slop-effect-schema-http/blob/main/LICENSE).

## Contribute a change

The [contributor
guide](https://github.com/viell-dev/slop-effect-schema-http/blob/main/CONTRIBUTING.md) owns checkout
setup, dependency policy, tests, documentation editing and pull requests. Start there when working
on the library itself.

For a defect report, use [Limits and recovery](./limits.md#report-a-defect). For confusing docs,
[open a documentation
issue](https://github.com/viell-dev/slop-effect-schema-http/issues/new?labels=Type%3A%20Documentation)
with the page, what you were trying to do, and what you expected to learn.

## Verify or publish a release

[Published candidate
checks](https://github.com/viell-dev/slop-effect-schema-http/blob/main/CONTRIBUTING.md#verify-a-published-candidate)
explain the supplied release checker.
[Releasing](https://github.com/viell-dev/slop-effect-schema-http/blob/main/RELEASING.md) owns
qualification, publishing, deployment and recovery. These procedures are for maintainers; ordinary
package installation is covered in [Getting started](./getting-started.md).
