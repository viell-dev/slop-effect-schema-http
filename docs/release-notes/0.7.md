# What's in 0.7

Runtime extension of 0.6's raw-edit check: the same generated-field loss can now be detected when
the renamed struct is inside an eligible closed union. The changed dimension is the group container;
it is not another fix to the direct-struct call already covered by 0.6.

`0.7.0` is a breaking release. Calls that silently replaced a later raw edit can now fail with
`Request.InvalidRequest` before dispatch. The [version policy](../versions.md) covers installation
and updates, and the [detailed changelog](../changelog.md) records the changes.

Compare the [related release family](./index.md#schema-input-hardening); use [Schema-backed
input](../schema-input.md) and [Schema-backed groups](../schema-groups.md) for today's contract and
active limits. The running schema below makes the changed route, container or layer directly
comparable with the previous release.

On `0.6.2`, compiling `overwritten` with `{}` sends `?page_size=25`, replacing the later raw `5`. On
`0.7`, it fails before sending and names `page_size`, without including its value in the error.

The proof requires an ordinary or null-prototype caller group with no own keys of any kind. Every
declared decoded and encoded name must also be absent from its prototype chain. All group shapes
through the finite union and its encoding steps must be closed objects or unions of closed objects.
Successful non-iterable output must actually hold the edited encoded field as an own enumerable data
property with a non-`undefined` value. No schema callback is evaluated again for this check.

An encoded alias can work at run time while TypeScript rejects it for a partly renamed struct
([#169](https://github.com/viell-dev/slop-effect-schema-http/issues/169)). The examples above use
the decoded name so they compile under strict TypeScript. Separately, an invalid value under a
renamed encoded name can be replaced by an optional constructor default
([#170](https://github.com/viell-dev/slop-effect-schema-http/issues/170)). Both limits predate
`0.7`; use decoded input or a decoded input mapping for these schemas until they are repaired. The
outer-object typing defect is repaired in [0.8](./0.8.md); invalid encoded-default selection
remains.

## Limits and existing behavior

A renamed or otherwise group-transformed schema with nonempty caller input still lacks general field
correspondence. Classes, declarations, suspended groups and open alternatives remain outside the new
union proof. Accessor or inherited field presence supplies no omission evidence. Iterable output is
governed by its yielded entries, so own string properties alone prove nothing about it.

The original constructor, decoder and member priority, validation, errors and effects remain in
place. Earlier raw defaults still work, and a binding removed with `Request.unbind` no longer
constrains that group. These checks do not repair conflicting aliases or expand union recovery; the
[Request guide](../modules/request.md#a-schema-states-the-shape-of-its-group) and
[limits](../limits.md) describe those separate boundaries.
