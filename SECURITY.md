# Security policy

Report a suspected vulnerability privately through [GitHub private vulnerability
reporting](https://github.com/viell-dev/slop-effect-schema-http/security/advisories/new). Do not
open a public issue for it.

Include the affected version or commit, a small synthetic reproduction, and what an attacker could
do with it. Keep credentials and private service data out of the report.

Fixes go into the newest release. Agents maintain this project, and its code is not human-reviewed.
